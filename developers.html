For Developers

1

Build Your Game

Create a self-contained HTML5 game using vanilla JavaScript or your favorite engine. Ensure it doesn't require server-side logic to run.

2

Prepare Assets

Package your index.html and assets in a folder. Provide a title, description, and an emoji or thumbnail for your entry.

3

Submit to Frybahn

Open a Pull Request on our GitHub repository to add your game to the data/games.json file and include your folder in /games.
